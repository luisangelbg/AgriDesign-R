# Colours of the AgriDesign figures

The categorical palette used by the figures of the package (forest
green, ochre, blue, brick red, plum...), recycled to `n` colours.

## Usage

``` r
agri_colors(n)
```

## Arguments

- n:

  Number of colours.

## Value

A character vector of colours.

## Examples

``` r
agri_colors(4)
#> [1] "#2f7d4f" "#c8842a" "#2b7bb9" "#b5432f"
```
