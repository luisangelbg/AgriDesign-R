# Maize nitrogen trial in wide format

The same trial as
[maize_nitrogen](https://luisangelbg.github.io/AgriDesign-R/reference/maize_nitrogen.md),
with one column per nitrogen rate. It shows the wide layout that has to
be reshaped to long format (one row per plot) before the analysis.

## Usage

``` r
maize_wide
```

## Format

A data frame with 4 rows and 5 columns: `Block` and the yields (t/ha) at
`N0`, `N60`, `N120` and `N180`.
